# Enemy squad prefabs

将配置好的 `EnemySquadCoordinator` 分支保存到这个目录。波次生成器接受任何以 `SquadGroup` 为根节点的 `.tscn`。

`goap_raider_squad.tscn` 是可直接复制修改的无 Qwen 示例，包含两名步枪兵和两名近战兵。

防守波次示例还提供：

- `scout_raider_squad.tscn`：2 名手枪侦察兵、2 名近战兵。
- `rifle_fireteam.tscn`：3 名步枪兵、1 名机枪兵。
- `assault_raider_squad.tscn`：2 名冲锋枪兵、2 名霰弹兵、2 名近战兵。
- `heavy_support_squad.tscn`：2 名步枪兵、2 名机枪兵、2 名精确射手。
