## AI 小队战斗系统 - 现状审计与五缺口设计

任务：审计 ai3d 决策管线，为 MVP 补五类战术意图。

**管线现状（已读源码确认）**：
- Utility 层 `squad_utility_evaluator_3d.gd`：17 种候选战术，AMBUSH 已有但只有开火优先级
- HTN 层 `squad_htn_planner_3d.gd`：AMBUSH 只有 `ambush_aim → ambush_volley` 两步，无部署/无同步就位/无超时兜底
- 角色分配 `squad_role_allocator_3d.gd`：BASE_OF_FIRE/MANEUVER_LEAD/MANEUVER_WING/SECURITY/BREACHER/RESERVE 六角色，回溯搜索+连续性奖励
- 调度器 `squad_task_scheduler_3d.gd`：`mark_member_succeeded` + `minimum_success_count` 做成员级同步；**无任务超时上限**
- 任务阶段 `squad_mission_controller_3d.gd`：MissionType 仅 CAPTURE_AND_HOLD / ELIMINATE_AND_RETURN；State 仅 APPROACHING/CLEARING/HOLDING/RETURNING/COMPLETE
- 计划编译器 `squad_plan_compiler_3d.gd`：BOUNDING_ADVANCE 单次 bound_move 无交换循环；BREAK_CONTACT 单次 RETURN_TO_ORIGIN 无交替撤退

**五缺口映射（关键结论）**：
1. REACT_TO_UNKNOWN_FIRE → 新增（现有 CONTACT_COVER 只在已确认接触后触发）
2. PREPARE_AMBUSH → 补部署链（WEAPONS_HOLD 移动 + 就位同步 + 超时兜底）
3. 交替跃进/撤退 → 改造 BOUNDING_ADVANCE/BREAK_CONTACT（加 swap 循环）
4. OCCUPY_AND_DEFEND → 部分已有（DEFEND_CONTACT/hold_objective）缺按入口/咽喉/射界分配+预备队
5. CONSOLIDATE_AND_REGROUP → 改造 recover_in_cover（缺换弹/集合掉队/重新分配）
